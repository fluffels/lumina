# Projektglossar

Die Begriffe beziehen sich auf die [Gewächshaus-Mission](mission-gewaechshaus.md) und ihre vereinfachte Simulation.

| Begriff | Bedeutung im Spiel |
| --- | --- |
| Trainingsdaten | Beispiele, mit denen der simulierte Pflanzenhelfer vorbereitet wird. Sie enthalten Merkmale und den tatsächlichen Pflanzenzustand als Referenz. |
| Trainingspool | Die Sammlung der Beispiele, die für die Vorbereitung des Helfers zur Verfügung stehen. Prüfpflanzen gehören nicht dazu. |
| Prüfdaten | Getrennte, zuvor nicht zur Vorbereitung verwendete Pflanzenbeispiele. An ihnen wird die Vorhersage des Helfers mit dem tatsächlichen Zustand verglichen. |
| Simulationsvertrag | Die in der Missionsspezifikation festgelegten Anforderungen an das vereinfachte Lernen und seine Darstellung. Die Simulation bildet keinen realen Modellanbieter nach. |

Eine hohe Trefferquote auf bekannten oder gleichartig verzerrten Beispielen belegt keine Verallgemeinerung. Auch eine ausgeglichene Trainingssammlung garantiert keine fehlerfreien Vorhersagen.
